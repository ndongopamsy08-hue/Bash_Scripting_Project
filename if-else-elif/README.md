# Folder Check Script

This Bash script checks if a folder exists in your **Documents** or **Desktop** directories.  

## How it works
1. The script asks you to **enter a folder name**.  
2. It checks if the folder exists in:
   - `$HOME/Documents`
   - `$HOME/Desktop`  
3. It displays a message:
   - ✅ Folder exists in Documents or Desktop  
   - ❌ Folder not found  

## Usage
Run the script in terminal:  
```bash
bash small-project-if-else.sh
