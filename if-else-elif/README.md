3️⃣ File Existence Check (filecheck.sh)

This script asks the user to enter a file name and checks if it exists in the current directory.

Usage:./filecheck.sh
File exists → prints: "The file <filename> exists"

File does not exist → prints: "The file <filename> does not exist, check if it has been registered"

4️⃣ File Empty Check (file.sh)

This script asks the user to enter a file name and checks if it is empty or not.

Usage:

./file.sh


Behavior:

File is not empty → prints: "<filename> not empty found"

File is empty → prints: "<filename> file empty found"

5️⃣ Folder Existence Check (small-project.sh)

This script asks the user for a folder name and checks if it exists in Documents or Desktop.

Usage:

./small-project.sh


Behavior:

Folder exists in Documents → prints: "Folder exists in Documents 📁"

Folder exists in Desktop → prints: "Folder exists in Desktop 🖥️"

Folder not found → prints: "Folder not found in Documents or Desktop ❌"
